## 2024-05-18 - Fix command injection in Sandbox fallback
**Vulnerability:** The command isolation sandbox (`Sandbox.execute`) fell back to executing commands via `sh -c` or `powershell` with unparsed string commands when `shlex.split()` failed to parse due to unmatched quotes or syntax errors. This bypasses array-based shell escaping and presents a command injection vulnerability.
**Learning:** Fallbacks intended to improve developer experience (e.g., executing malformed strings in a subshell) can completely undermine the primary security isolation mechanism if they revert to inherently unsafe functions like `sh -c`.
**Prevention:** If the safe parsing mechanism (`shlex.split()`) fails to interpret input securely, the operation must be rejected entirely rather than passed on to a less secure evaluation layer.
## 2024-05-24 - Restrict FastAPI CORS Middleware configuration
**Vulnerability:** The `CORSMiddleware` in `src/nexus_agent/gui/server.py` was instantiated with `allow_methods=["*"]` and `allow_headers=["*"]`. This overly permissive configuration is considered a High Priority issue and allowed any HTTP method and arbitrary headers.
**Learning:** Using `["*"]` for CORS methods and headers in an ASGI application, especially one operating locally on `127.0.0.1` and `localhost` with `allow_credentials=True`, creates unnecessary exposure to malicious interactions from other local origins and violates principle of least privilege.
**Prevention:** Always restrict CORS `allow_methods` (e.g., `["GET", "POST", "PUT", "DELETE", "OPTIONS"]`) and `allow_headers` (e.g., `["Content-Type", "Authorization", "Accept"]`) to the explicit and minimal set of HTTP methods and headers required by the application's endpoints.
