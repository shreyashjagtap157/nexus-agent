
## 2024-06-15 - [Replace slow pathlib.rglob with fast os.scandir for directory traversals]
**Learning:** Using `pathlib.Path.rglob()` for recursive directory traversal creates significant overhead because it creates intermediate `Path` objects. A custom recursive `os.scandir` implementation is much faster for tasks like finding GGUF files and calculating disk usage, especially when handling deeply nested folders.
**Action:** When optimizing file system traversal or repeated `stat` checking in hot loops, prefer `os.scandir` with explicit `follow_symlinks` flags instead of `pathlib.rglob()`.
## $(date +%Y-%m-%d) - [Replace slow os.walk with fast os.scandir for directory traversals]
**Learning:** Using `os.walk` for recursive directory traversal creates significant overhead because it eagerly builds lists of all files and directories in memory for every directory it visits. Using a custom recursive generator over `os.scandir` (like `iter_files`) allows for lazy traversal and prevents OOM and performance bottlenecks when scanning large workspaces.
**Action:** When replacing `os.walk` with custom utilities like `iter_files()`, ensure you natively support skipping excluded directories during traversal (e.g., via an `exclude_dirs` argument) and explicitly pass arguments like `include_hidden=True` to preserve original behavior. Also, when pulling out inline skip lists, use global `frozenset` constants to avoid set reallocation overhead on every function call.
