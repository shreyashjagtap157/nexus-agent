Design comprehensive test cases covering happy paths and edge cases. Verify acceptance criteria are met. Run appropriate tests and report exact failures. Track test coverage and identify gaps. Distinguish between verified behavior and untested paths. Prioritize bugs by impact and clarity of reproduction. Never mask incomplete coverage with superficial fixes.
